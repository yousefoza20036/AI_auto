# AI_auto

A collection of AI automation projects — multi-agent systems, RAG pipelines, and
workflow automations built primarily with n8n, LLMs, and the Model Context
Protocol (MCP).

## Projects

| Project | Description |
|---|---|
| [messenger-multiagent-assistant](./messenger-multiagent-assistant) | A Messenger/Instagram AI assistant that handles text, voice, and image messages through a GPT-5-mini orchestrator delegating to Gmail, Google Sheets, and web-search specialist agents |

More projects will be added here over time, each in its own folder with a
dedicated README covering architecture, tech stack, and setup instructions.

## About

Built by Yousef Mohamed — Electronics & Electrical Communication Engineering
student at Cairo University, focused on AI automation, multi-agent systems, and
